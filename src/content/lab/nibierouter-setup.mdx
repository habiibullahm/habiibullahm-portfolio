  - "Added an admin MCP server in the Cursor user config. get_system_info returned version 1.0.14."
decisions:
  - "Keep https://sr-44e28f.jkt11.sumopod.my.id as the machine address until SumoPod enables custom domain on this SumoRouter service."

  - "nibie.app is the company name. nibie.com was already registered by someone else."

learnings:
  - "Test /v1/models on the host you will ship. The sample base URL in the docs is not this instance."
  - "402 has two causes. this API key has reached its credit limit is the key cap, not an empty Sumopod AI balance."
  - "A trailing dot on the webhook path is a different environment name."
  - "A CNAME to a SumoPod hostname is not a custom domain. SumoPod has to accept the name, and this service has that switch off."
  - "NibieRouter credit and Sumopod AI credit are spent in that order. One balance does not refill the other."
